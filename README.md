# Интернет-магазин «Накарбине» — моделирование данных и БД

## Контекст
Учебный проект интернет-магазина «Накарбине».  
В рамках проекта выполнялось моделирование данных и проектирование базы данных для веб-приложения интернет-магазина.

## Цель проекта
Разработать логическую модель данных и структуру базы данных, отражающую бизнес-логику интернет-магазина и пригодную для дальнейшей реализации.

## Роль
Системный аналитик

## Задачи аналитика
- Анализ предметной области интернет-магазина
- Выделение ключевых бизнес-сущностей и их атрибутов
- Проектирование связей между сущностями
- Формирование логической модели данных
- Подготовка словаря данных
- Актуализация спецификации требований в части работы с данными

## Артефакты
- Логическая модель данных
- ERD (Entity-Relationship Diagram)
- Словарь данных
- Обновлённая спецификация требований
- SQL-структура БД (опционально)

## Результат
Разработана логическая модель данных и структура базы данных интернет-магазина «Накарбине».  
Модель учитывает основные бизнес-сущности, связи и ограничения целостности и может быть использована как основа для реализации БД.
